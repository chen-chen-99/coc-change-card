# 卡牌图片目录

把卡牌图片放到本目录，构建时会随网页一起部署（`public/` 目录会被原样复制到 `dist/`）。

## 当前状态

- 目录内为 **60 张官方兵种立绘**（来源：Clash of Clans Fandom Wiki，透明背景 PNG，512×512），按 4 个种类分组。
- 获取 / 处理步骤与 60 张卡牌的 Wiki 页面对照见 `docs/card-image-prompt.md`。

## 命名规则（重要）

**文件名 = 数据库 `cards` 表的 `card_id` + `.png`**，卡牌 ID 按种类使用前缀：

| 种类 | card_id 前缀 | 图片示例 |
| --- | --- | --- |
| 圣水卡牌（19 张） | `e` | e01.png ~ e19.png |
| 暗黑重油卡牌（13 张） | `d` | d01.png ~ d13.png |
| 建筑大师基地卡牌（11 张） | `b` | b01.png ~ b11.png |
| 超级兵种卡牌（17 张） | `s` | s01.png ~ s17.png |

## 要求

- **格式**：PNG（透明背景优先）；也可以使用 WebP / JPG，但需要同步修改 `cards.image_url` 字段
- **尺寸**：512 × 512（源图等比缩放、透明补齐，不裁剪兵种主体）
- **大小**：单张 ≤ 1MB
- **文件名**：全小写、无空格、无中文
- **内容**：官方兵种立绘，不修改外观、不加文字水印
- 想换自己的图：按上表同名覆盖 `e01.png`、`d01.png` 等即可，无需改代码
- 如果某张图片缺失，页面会自动显示占位图（卡片名 + 底色），不影响使用
